📘 LogicAR

دليل المشروع الكامل — شرح للمبتدئين والمطورين

🔷 1. المشروع ده بيعمل إيه؟

LogicAR هو موقع تعليمي تفاعلي لتعلم البوابات المنطقية (Logic Gates) والدوائر الرقمية بتقنية الواقع المعزز (AR).

  • 📖 شرح تفاعلي لكل بوابة مع جداول حقيقة
  • ⚙ محاكي دوائر (سحب وإفلات وتوصيل)
  • 🥽 تجربة واقع معزز — مجسمات 3D للبوابات
  • 🗺 خريطة كارنوف لتبسيط المعادلات
  • 🌐 دعم اللغتين العربية والإنجليزية

🔷 2. التقنيات المستخدمة

التقنيةالاستخدام

⚡ ملاحظة: المشروع بدون Frameworks (React/Vue) وبدون Backend — ملفات ثابتة فقط.

🔷 4. شرح كل صفحة بالتفصيل

📄 4.1 index.html — الرئيسية

شريط تنقل + Hero section + مميزات + معاينة البوابات + خطوات البدء + Footer.

📄 4.2 learn.html — التعلم

شرح 7 بوابات (AND, OR, NOT, NAND, NOR, XOR, XNOR). كل بوابة فيها رمز SVG، جدول حقيقة، تجربة تفاعلية بمفاتيح وLED.

📄 4.3 combinational.html — الدوائر التوافقية

نصف الجامع (Half Adder)، مبدل 2:1 (Multiplexer)، مُفكك تشفير 2:4 (Decoder).

📄 4.4 sequential.html — الدوائر التعاقبية

SR Latch، D Flip-Flop، JK Flip-Flop، عداد 4-bit، مسجل إزاحة (Shift Register).

📄 4.5 simulator.html — المحاكي ⭐ الأكثر تعقيداً

يمكنك إضافة بوابات، مدخلات، مخرجات، توصيلها بأسلاك، مع جدول حقيقة تلقائي ومعادلة منطقية.

  • nodes[] — كل العناصر
  • wires[] — كل التوصيلات
  • simulate() — باستخدام Topological Sort
  • generateCircuitTruthTable() — تجربة كل التركيبات

📄 4.6 kmap.html — خريطة كارنوف

اختر 2/3/4 متغيرات، غيّر القيم (0/1/X)، وتحصل على المعادلة المبسطة تلقائياً.

📄 4.7 ar.html — الواقع المعزز

يستخدم A-Frame + AR.js لتحميل الكاميرا وعرض مجسم 3D للبوابة فوق العلامة المطبوعة.

📄 4.8 markers.html — العلامات

توليد علامات قابلة للطباعة (Barcode patterns) لاستخدامها مع AR.

🔷 5. ملف التصميم style.css

CSS Variables RTL Support Animations

:root {
  --bg-primary: #060614;
  --accent-cyan: #00d4ff;
  --accent-purple: #8b5cf6;
  --accent-green: #00ff88;
}

أقسام الـ CSS: Global, Animated Background, Navbar, Buttons, Learn Page, Simulator, AR, K-Map, Utilities.

أنيميشن الـ Scroll: استخدم كلاس reveal مع IntersectionObserver.

🔷 6. نظام الترجمة i18n.js

كائن translations بمفاتيح ar و en. العناصر تستخدم data-i18n="key". عند تغيير اللغة، يتم تحديث كل النصوص واتجاه الصفحة (RTL/LTR).

🔷 7. كيف تشغّل المشروع

  • مباشر: افتح index.html双击
  • بـ Live Server (موصى به للـ AR): 
    python3 -m http.server 8000
⚠️ الـ AR يحتاج HTTPS أو localhost بسبب الكاميرا.

🔷 8. كيف تعدّل على المشروع

🎨 تغيير الألوان

غيّر قيم المتغيرات في :root داخل style.css.

➕ إضافة بوابة جديدة في learn.html

أضف كائن داخل مصفوفة gates:

{
  id: 'new_gate',
  name: 'NEW',
  compute: (a,b) => a & b,
  truthTable: [[0,0,0],...],
  symbol: `<svg>...</svg>`
}

➕ إضافة صفحة جديدة

انسخ صفحة موجودة، غيّر المحتوى، وأضف رابطاً في شريط التنقل.

🔷 9. مفاهيم برمجية مهمة

  • التواصل بين الصفحات: localStorage للغة + روابط عادية.
  • إنشاء المحتوى ديناميكياً: يتم بواسطة JavaScript وليس HTML ثابت.
  • الأحداث المخصصة: CustomEvent('languageChanged')

🔷 10. نصائح للمبتدئين

  • ابدأ بقراءة index.html
  • جرّب تغيير الألوان في CSS Variables
  • استخدم F12 لتجربة تعديلات لحظية
  • اختبر على الموبايل لتجربة AR
